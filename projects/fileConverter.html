File Converter

A desktop utility built in C# and .NET that lets users convert files between common formats through a clean, straightforward interface. Built to explore application development outside of the web.

Back to projects

Project snapshot

Role: Developer

Focus: Desktop utility, file handling, UI

Status: Completed

Goals and approach

The goal was to build a practical desktop tool that handles file format conversion reliably, while keeping the interface simple enough for any user to pick up immediately. This project pushed me into C# and .NET application development beyond the browser, covering file I/O, event-driven UI, and error handling.

Key features

File selection, format conversion between supported types, and clear feedback on success or failure.

User interface

Clean, minimal UI built to keep the user focused on the task — pick a file, pick a format, convert.

What I learned

Practical experience with C# file handling, .NET desktop application structure, and building event-driven UIs.

Tech stack

C# .NET Desktop UI

Outcome

A working desktop utility that demonstrates practical C# and .NET skills. Building outside of the web stack gave me a broader perspective on application architecture and strengthened my understanding of typed, compiled languages.
