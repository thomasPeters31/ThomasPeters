Portfolio Website

A polished, fast-loading personal site that presents my background, skills, and projects in a clear, recruiter-friendly format. Built to be responsive, accessible, and easy to expand as new work comes in.

View repo Back to projects

Project snapshot

Role
Designer + Developer
Focus
Personal branding, clarity, speed
Status
Live

Goals and approach

The primary goal was to create a single-page experience that communicates strengths quickly to recruiters and potential clients. The layout puts core information front and centre, with individual case study pages for each project to keep the homepage clean without losing detail.

Design

A distinct visual language with a clear hierarchy — the work speaks first, styling supports it.

Performance

No frameworks or heavy dependencies — lightweight HTML, CSS, and JS with subtle fade-in animations.

Maintainability

Structured sections and shared styles make it straightforward to add new projects or update content.

Tech stack

HTML CSS JavaScript GitHub Pages

Outcome

A live, recruiter-ready portfolio with individual case studies for each project. The site is hosted on GitHub Pages, fast to load, and straightforward to extend — this page is itself part of it.
