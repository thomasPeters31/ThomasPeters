CounsellingHQ

A professional website built for a counselling service client, designed to be welcoming, clear, and easy to navigate for people seeking mental health support.

View repo Visit live site Back to projects

Project snapshot

Role
Designer + Developer
Focus
Client website, accessibility, trust
Status
Live

Goals and approach

The client needed a calm, professional online presence that would make visitors feel at ease and clearly communicate the services on offer. The design prioritises readability and a reassuring tone, with straightforward navigation so users can quickly find the information they need.

Key features

Clear service overview, contact information, and an approachable layout built for a non-technical audience.

Design

Calm colour palette and clean typography chosen to reflect trust and professionalism in a sensitive sector.

Client work

Collaborated directly with the client to capture requirements and iterate on the design until it matched their vision.

Tech stack

HTML CSS JavaScript

Outcome

The finished site gives the client a polished, professional web presence that serves their users well. It is live and demonstrates real-world experience delivering a complete website for a paying client.
