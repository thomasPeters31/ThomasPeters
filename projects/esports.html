Esports Website

A modern, competitive identity for an esports team, focused on bold visuals, clear team information, and easy updates for upcoming matches. The project is in active development with iterative design reviews.

View repo Live site Back to projects

Project snapshot

Role: Designer + Developer

Focus: Branding, team profiles, match updates

Status: In development

Design direction

The site leans into a high-contrast esports aesthetic while keeping typography and content structure readable. Sections are designed to spotlight roster details, team achievements, and match schedules without overwhelming visitors.

Planned features

Team profiles, match calendar, news updates, and highlight reels.

Content workflow

Reusable sections to allow quick updates as the roster or matches change.

Visual tone

Bold gradients, strong imagery, and clear hierarchy for quick scanning.

Tech stack

HTML CSS JavaScript UI/UX

Next steps

Finalize the match schedule module, integrate team media assets, and run a performance pass before launch.
