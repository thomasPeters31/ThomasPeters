Esports Website — Yokai

A multi-page website for the Yokai competitive gaming organisation, built around a Japanese-folklore identity — the name refers to yōkai (妖怪), spirits from Japanese folklore, with the tagline "we compete like the folklore." The site is structured to cover the organisation's story, rosters, schedule, news, and partnerships.

View repo Visit live site Back to projects

Project snapshot

Role
Designer + Developer
Focus
Brand identity, multi-page structure, responsive layout
Status
In development

Goals and approach

The organisation needed a website that carried its folklore-inspired branding while staying readable and easy to navigate. I built it as a hand-coded static site with a shared header, footer, and stylesheet across every page, so the layout stays consistent and the content is straightforward to expand as the team fills in real rosters, results, and news.

Design direction

A dark, high-contrast theme with a kanji (妖怪) motif, Shippori Mincho for display headings and Inter for body text, and subtle scroll-reveal animations to give the pages movement.

Site structure

Seven pages — home, about, teams, schedule, news, sponsors, and contact — each with its own layout for roster cards, a milestone timeline, a news grid, and a partner logo strip.

Front-end build

Plain HTML, CSS, and JavaScript with no framework. JS handles the mobile navigation toggle, scroll-reveal effects, and active-link highlighting; the site is deployed on a custom domain.

Tech stack

HTML CSS JavaScript Responsive design UI/UX

Outcome

The full page structure, navigation, and visual identity are in place and deployed to a custom domain. The site is still in development while the organisation supplies the real content — team rosters, match schedule, news articles, and partners — which the templates are built to drop straight into.
